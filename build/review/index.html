LEVELS — THREE FLOORS, ONE WAY DOWN

The campaign runs Level 0 → 1 → 2, one station per floor, stairwells east. There is no way back up. The white-door exit is on the bottom floor only:

  • Level 0 · The LobbyYellow halls. Station 01 in the west offices; stairs past the server hall.
  • Level 1 · Concrete HallsBare concrete, damp air. Station 02 in the north hall; stairs east.
  • Level 2 · Pipe DreamsCold machine rooms laced with pipe runs. Station 03 north, white door east.
